Hardened Images Launch Lab

Build the dinner app (a Python app and a PostgreSQL database) on Docker Hardened Images: pull and run them, do a multi-stage build, scan with Docker Scout and run it all with Compose. Pick how you want to run the lab.

    In a Docker Sandbox

    Instructions, VS Code and a private Docker engine in a single microVM, with sbx. One kit set, nothing to clean up on your machine afterwards: sbx rm removes everything the lab created.

    sbx run ghcr.io/mathieu-benoit/labsbx-dhi-launch:latest -p 8085:8085 -p 5001:5001 --name dhi-launch -d

    With Docker Compose

    The Labspace on the labspace-infra Compose stack, anywhere Docker and Docker Compose are installed. Then open http://localhost:3030.

    docker compose -f oci://ghcr.io/mathieu-benoit/labspace-dhi-launch:latest up
